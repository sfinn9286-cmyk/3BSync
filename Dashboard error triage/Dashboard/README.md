`GET /soc` (private webpage). The SOC console — a dark terminal-style UI showing the live alert feed with severity filters, summary stats, and a detail drawer with the AI's summary, recommended actions, MITRE mapping, and reasoning. A "Generate Sample Alert" button POSTs to `/soc-ingest`. Data is fetched from [Alerts API](<../Alerts API/script.ts>); the `?branch` param is forwarded so drafts read their own data.
